## Publish
Upload index.html, preview-envelope.jpg and .nojekyll to the repository's main branch root. Under Settings > Pages choose Deploy from a branch, main, / (root). README.md is optional.

## Verification

Mobile Chrome emulation at 390 px: no horizontal overflow, envelope opens, all gallery images load when requested, no severe browser errors excluding favicon. Preview JPEG verified as 1200 x 630. Source HTML body exactly preserved.

## Important limitations
The website was not published: GitHub returned HTTP 403 Resource not accessible by personal access token when creating the repository. The intended URL is not yet live.

WhatsApp controls fetching/caching and displaying link previews; correct Open Graph tags and a publicly available JPEG do not guarantee display on every device. Send the website URL, not the HTML attachment.

The RSVP form in the supplied HTML saves responses only in each guest's browser localStorage. It does not send the host a notification or collect replies centrally. Existing event/transport/accommodation details were preserved, not independently confirmed.
